# Summary

Free the D-pad from the To field. With a controller, the Send Mail tab lets the cursor move again.

- Mail

# Description

With the controller UI on, opening the Send Mail tab puts the cursor in the To field. A text field holds the D-pad, so the cursor can't leave it, and the mail can't be closed with B. The only way out is to walk away from the mailbox.

[![Support me on Ko-fi](https://images.weserv.nl/?url=storage.ko-fi.com/cdn/kofi5.png&h=36)](https://ko-fi.com/artisangw)

This addon lets go of the To field as soon as the game focuses it: when the tab opens, and after each mail you send. The D-pad moves the cursor at once. Press A on a field to type in it, as before.

It's a simple tool with no dependencies:
- On as soon as it's installed
- Only with a controller: with mouse and keyboard, nothing changes
- /gpmf says what it does
